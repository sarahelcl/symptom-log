Symptom log: put these files online, then install on your phone.

Easiest: Netlify Drop
1. Go to app.netlify.com/drop and sign up (free).
2. Drag this whole folder (the unzipped one) onto the page.
3. Open the address it gives you on your phone.
   iPhone: open in Safari, tap Share, then Add to Home Screen.
   Android: open in Chrome, tap the menu, then Install app.

Keep all files together in one folder. Your entries are saved on the phone itself.
If you change a file later, change VERSION in sw.js so phones update.
